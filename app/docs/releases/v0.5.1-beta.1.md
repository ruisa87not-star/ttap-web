# TTAP Planner 0.5.1-beta.1 — Windows Beta

First downloadable Windows installer for the redesigned TTAP Planner.

## Download and install

1. Download **TTAP-Planner-Setup-0.5.1-beta.1-x64.exe** from this release's Assets.
2. Run the installer and choose your installation folder. It installs for your
   Windows account and creates desktop and Start menu shortcuts.
3. Open **TTAP Planner**. Complete or skip the tutorial, then import UTAR course
   HTML or choose Try demo.

Node.js, npm, source code and Start-TTAP.cmd are not required. GitHub's Source
code ZIP/TAR downloads are for developers; they are not the Windows installer.

For removal, use Windows Installed apps → TTAP Planner → Uninstall.

## Included

- Integrated official UTAR login and a guided HTML importer.
- An 18-course demonstration catalog with lecture/tutorial choices.
- Immediate clash checks, disabled conflicting courses, group selection and Clear.
- Mon–Sun timetable rows with horizontal hours, unavailable time and summaries.
- PNG timetable/registration-guide export and protection for unexported changes.
- The supplied fork logo, maximized startup and responsive panels.

## Beta notes

- Windows x64 only. Tested on Windows 11 x64; Windows 10 has not been verified.
- **Unsigned build:** no Authenticode certificate is configured. Windows may
  display an unknown-publisher or SmartScreen message, and managed computers may
  block unsigned software. Verify the repository URL and the included SHA256SUMS.txt.
- No automatic updater. Download subsequent versions from this repository's Releases.
- UTAR login, CAPTCHA and registration are handled by the official UTAR website.
  No real account login or course-registration submission was performed for this
  release. Always confirm actual class availability in UTAR.
- HTML parsing is covered by archived UTAR formats and synthetic fixtures; a
  current authenticated UTAR HTML export has not been supplied for verification.
- Installation validation uses a new isolated folder/profile on the existing
  Windows host. A clean Windows VM or separate physical machine was not available.
